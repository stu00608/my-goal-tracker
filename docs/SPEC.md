# Goalooker - 過路客：產品 spec

## 使用與技術範圍

約 10 位使用者，各自的紀錄獨立私密。第一版只在 iPhone 儲存資料，支援手動匯出與還原。
目前只部署到開發者自己的 iPhone，使用免費 Apple Personal Team；付費會員與朋友發佈方式留待後續決定。

使用 Swift、SwiftUI、SwiftData、Swift Charts。第一個 app 專案暫定最低 iOS 17；
建立時確認本人的手機版本與可用 Xcode，需調整時明確記錄原因。
不需要 server、登入、CloudKit、Cloudflare、Android 或遊戲服務整合。

## 領域

- 追蹤項目：使用者關心的事情，包含名稱、記錄方式、排序與封存狀態。統計時區屬內部日期資料，不作為每個項目的唯讀設定欄位呈現。
- 紀錄：實際發生時間、建立／更新時間、數值或完成日期、文字、照片與選填位置。
- 目標：選填的期限或頻率規則，保留已生效的歷史規則。

有紀錄後，改變記錄方式或單位需要明確的轉換方案；第一版以建立新項目處理。

## 數值快照

例如 Volforce、體重、考試成績。使用者自行輸入數值，可設定單位、顯示小數位與改善方向。
支援不定期記錄、補登、編輯、刪除、照片與說明；允許數值下降。
新增數值可輸入新數值或正負變化值；變化值以前一筆發生時間不晚於這筆的數值為基準，
補登依選定日期找基準，編輯時排除該筆本身。沒有基準時需直接輸入首筆數值。
新增畫面上方集中呈現數值輸入、調整與結果。輸入種類維持點按選單選「新數值／變化值」。模式名稱、大數值及基準→結果皆置中，直接呈現在頁面上，不包卡片。僅變化值可上下滑動，以短促可中斷的數字滾動動畫回饋；新數值只支援點按輸入，上下滑動保持正常捲頁。減少動態效果時數字立即更新。變化值依顯示小數位的最小單位（10^-precision）調整；向上增加、向下減少，變化值可跨過零成為負值，毋須手打正負號；點按大數值則直接輸入。數值拖曳與外側整頁捲動分開處理。
顯示基準與計算結果，以 Decimal 保留精度。新數值保存絕對值，變化值保存原始正負增量。依發生時間、建立時間與 UUID 穩定排序，增量由前一個已解析數值累加；遇到新的絕對值重新起算。補登、編輯或刪除會重新解析後續增量直到下一個絕對值，其他原始增量不改寫。舊版紀錄維持絕對值，不能猜測原本輸入方式。編輯增量載入原始增量並說明連動；不得捨入原值。沒有前置基準或解析溢位時不能儲存。刪除／改日期造成首筆孤立增量時，明確詢問是否以該筆變更前的解析值轉成新基準；取消保留原資料。
以發生時間判定最新值。儲存與匯出保留精度，日期沒有紀錄時不生成實際紀錄。

顯示最新值、最佳值、上一筆差異、所選期間首末紀錄差異、距離目標的差距。
30 天、90 天、全部與自訂日期區間都保留圖表；區間沒有紀錄但有先前數值時，可顯示沿用值並標示最後紀錄日期；沒有先前資料則顯示空狀態。
自訂期間以項目的統計時區涵蓋起訖日期整天，不能倒置；預設區間不包含未來。
圖表的實際點連結到紀錄詳情與照片；一筆資料不生成成長幅度。用獨立虛線段將最後已知數值延伸到現在或所選期間末端的較早者，區間開始前有基準時亦可沿用至首筆紀錄。延伸段不是量測或紀錄，沒有可選的虛構端點，不影響統計、達標或匯出，也不延伸到未來。概覽圖表可在項目內選填 Y 軸上下界，未填側使用自動範圍；兩側皆填時下界需小於上界，超出範圍的資料不改寫，裁切與說明須明確。
期限目標支援向上／向下的門檻，期限前曾有有效紀錄達到門檻即達成。
修改或刪除紀錄後重新計算，不保留已失去依據的達標狀態。

## 完成紀錄

例如煮飯、洗澡、到辦公室。不要求每天記錄；同一天最多計入一次，可取消、補登、附照片與文字。
每週／每月至少 N 次是不同日期的完成次數；不是要求每天完成。
未勾選代表沒有完成紀錄，介面避免推斷使用者實際沒做。

- 每週預設週一至週日，每月為曆月；使用 Calendar 計算，沒有固定 30 天的月份。
- 建立時保存統計時區與紀錄的當地日期，旅行不改變過去紀錄所屬日期。
- 跨期重新開始計數。超額保留真實次數，例如 3/2。
- 新項目的第一個不完整期間標示為部分期間，不納入完整期間達標率。
- 頻率變更預設下一個完整期間生效；歷史期間按當時規則分析。

詳情可切換日曆、長條圖與進度條。日曆保留完整的每月日期與補登入口。
長條圖呈現歷史每週／月不同日期完成次數與當期目標，部分期間清楚標示；沒有目標時
顯示近期每週紀錄次數。進度條呈現當期次數／頻率目標，超額完成保留真實數字，
填色最高滿格；未設定頻率目標時顯示說明。另保留完整期間達標率。

## 介面與資料

主要分頁為今天、目標、完成、設定；設定位於底部分頁最右側，沒有額外齒輪入口。項目詳情包含圖表或日曆、目標進度、紀錄時間軸。
設定包含首頁清單／網格、外觀、語言、預設數值輸入方式、新紀錄位置預設、App 提醒總開關、匯出／還原與儲存資訊；個別提醒在追蹤項目內設定。
「今天」預設雙欄網格卡片；大字體縮為單欄。點卡片或清單項目開啟新增紀錄 sheet；
完成項目今天已有紀錄時開啟該筆，避免重複。從「目標」分頁進入分析與管理。
首頁只保留卡片紀錄的主要動線；以長壓拖曳排序，VoiceOver 保留移動操作，未設定的 Widget 沿用首個項目。
清單的完成／新增操作統一放在右側；卡片下方不另設詳情或排序工具列。
每個項目可選圖表、最新紀錄照片、項目照片（第一張）、位置地圖或目標進度圓餅／環作卡片背景，無相應資料時使用清楚的空狀態。目標進度背景必須已有目標，完成型使用當期頻率次數；數值型使用有效目標的起始值到門檻的進度。
背景填滿整張卡片，標題、數值與狀態疊在背景上，概覽不要求所有圖表細節都可見。
一般字級的網格為正方形；標題與數值／選填最後紀錄日期依項目設定在四個角落之一的同一透明文字群組，可隱藏；地圖背景只可選左上、右上或隱藏，舊的下方位置按同側解析成上方，不覆寫原偏好；地圖鏡頭在有文字時向上方與文字側延伸，讓位置圖釘落在文字下方與另一側，背景仍滿版；初始為右下且顯示日期；進度環例外，文字強制置中，進度數字下方接標題與選填日期，不提供位置選項，切回其他背景保留原本位置偏好；卡片與 Widget 不顯示超出圖表範圍的提示；概覽只顯示日期本身，完整「最後紀錄」語意由無障礙摘要保留。完成型非圓環卡片的標題與日期保持所選角落對齊，數值列與勾選圈共用一列，只為該列預留操作空間，不縮排整組文字；App 快速完成按鈕以數值列的實際位置對齊並保留右側操作，跟隨文字區塊；文字隱藏時地圖按鈕放右上，其他背景放右下。點按直接紀錄／取消，整張卡片仍開啟紀錄 sheet；取消帶有照片、說明或位置的紀錄須先確認，不跳到編輯器，不另加底板或加號。照片／地圖以細緻文字輪廓維持對比。概覽圖表保留實際時間間距，Y 範圍至少包含數值量級 10% 或十個最小精度單位，再加入資料範圍留白，避免微小變化被誇張放大；圖表四側的像素內縮相近（約 12–14pt），不因文字高度壓縮圖像；詳情仍按所選期間呈現分析。Widget 使用同一背景與文字群組，系統 Widget 本身就是外形，不加入內層卡片。調色／透明模式依 widgetRenderingMode 調整背景圖像與不透明度，文字及完成狀態保持明確可辨。大字體及增加對比時優先保持可讀。
點照片開啟全螢幕檢視，可放大、縮小，切換同筆紀錄的其他照片及關閉。

預設數值輸入方式初始為新數值，只影響後續新增；有基準時可預設變化值，首筆／選定日期沒有基準時回到新數值。編輯既有紀錄載入原始的新數值／變化值類型及數值；單筆切換不修改偏好。

設定中的新紀錄位置預設初始關閉，只影響後續新增紀錄；設定切換本身不請求定位，既有紀錄依原本位置狀態開啟。
每筆紀錄仍有獨立的位置開關；選照片時只暫存第一張的 GPS，開啟才保存位置。沒有有效 GPS 才請求手機目前位置。
只取第一張原始照片的資訊，不改用其他張；日期與位置分開處理。
目前位置明確標示為目前所在處，避免誤認為補登日期的歷史位置；拒絕權限或定位失敗
不阻擋紀錄保存，也不捏造座標。編輯既有紀錄保留位置，關閉開關明確移除該筆位置。
一般記錄位置不持續追蹤、不要求背景定位；條件達成提醒另按下節使用系統區域監測。有座標的項目詳情顯示地圖與各筆標記，點標記可查看紀錄。
位置與卡片背景包含在完整備份，舊版缺少欄位仍可還原；CSV 追加 latitude、longitude。

新增／編輯的上方工作區使用緊湊照片列，加照片入口不放到整頁末端。照片點按開啟放大檢視；移除從該張照片右上角略微凸出的紅色圓形按鈕發起，命中區至少 44pt，完整點擊範圍與凸出部分不被裁切，顯示對應預覽並允許取消，保存前不刪除既有紀錄中的副本。
控制項與其說明及狀態保持同一群組；各表單支援點按非輸入處、互動捲動及完成控制收起鍵盤。
照片保存 app 自有副本，刪除相簿原圖不影響已保存的紀錄。
新增紀錄尚未手動改日期且沒有附件時，首次選照片帶入第一張（依選取順序）的拍攝日期。
只讀第一張的日期，不改採其他張；沒有有效日期或日期在未來時保留原日期。
照片含時區偏移時保存該實際時間；缺少偏移時按項目的統計時區解讀。
日期帶入後仍可手動修改；新增更多照片、編輯舊紀錄及已選日期的日曆補登不覆蓋日期。
同日每日紀錄合併照片也遵守 10 張上限，超出時不保存並保留原紀錄。
CSV 用於外部分析；完整備份包含項目、目標歷史、原始數值／增量、紀錄、全部附件與格式版本。新版格式為 3，仍可載入舊版 1、2；舊版 App 不能讀取新版備份。首次載入舊版 Ledger 時先在 App 私有儲存保留原始 v2 遷移前副本，失敗不重寫原資料；舊版空位置列表的休眠 gate 旗標還原成未啟用，已設定的條件完整保留。CSV 保存解析後數值，並於既有欄位尾端追加 input_kind、change。匯出檔名含固定 UTC 毫秒時間戳記，JSON 名稱使用 Goalooker-backup，CSV 使用 Goalooker-export，避免覆蓋同名檔案。
還原先完整驗證、顯示摘要、確認後取代；失敗保留原有資料。第一版不合併不同備份。

所有文字支援繁體中文、日文、英文，使用 String Catalog 與系統日期／數字格式。
使用者輸入的名稱與筆記保留原文。外觀支援亮色、暗色、系統。
以原生導覽、sheet、控制項與系統字體為主；提供 Dynamic Type、VoiceOver 與減少動態效果支援。
Liquid Glass 限於適用的導覽／控制層，內容保持清楚可讀。

UI 變更需遵守 [原生 UX 品質標準與反覆檢視流程](UX-QUALITY.md)，以實際操作與最終畫面驗收。

## 里程碑與驗收

1. App 基礎：shared scheme、Swift Testing 與 XCTest UI test targets、三語、外觀與可執行 CI。
2. 核心記錄：兩種項目、紀錄、目標、照片、圖表／日曆、完整備份與還原。
3. 本機提醒：指定時間／星期與期限提醒，啟用時才請求權限。
4. Widget 可行性與實作：完成清單、最新數值與目標差距；先確認 Personal Team 對必要 entitlements 的支援。

Widget 共用資料涉及 App Groups 等能力；Simulator 無簽名執行不能證明能用免費帳號部署到手機。
Widget 不得成為核心 app 免費簽署的前置依賴；需要會員的能力獨立處理。

核心驗收：重複勾選不多算；跨週／跨月與時區正確；補登不誤判最新值；
離線及重開 app 可保留資料；刪除相簿原圖後附件仍在；
備份還原後數值、日期、文字、目標歷史與照片一致；損壞備份不改動既有資料。

## 第一版實作界線

最低 iOS 17，以 Xcode 26／Swift 6 編譯，無第三方 runtime dependencies。
數值可輸入正負十進位數，最多 28 位數字，不接受科學記號或千分位。
顯示小數位 0–8，不改變已保存精度。完成型項目名稱可重複，身份由 UUID 判定。
照片使用 PhotosPicker，保存獨立 JPEG 靜態副本，不保留 Live Photo 影片，每筆紀錄與每個項目各最多 10 張、1600 像素、每張 2 MB。新匯入以品質 0.8 起算，必要時降低品質以符合容量；極高細節在品質 0.65 仍超過上限時再縮小至 1440／1280 像素，避免繼續犧牲 JPEG 品質。既有副本不重新壓縮。
完整備份 JSON 上限 100 MB；先驗證完整內容與照片再允許取代。CSV 不含照片，
文字欄位防止試算表公式執行；分析匯出不代替完整備份。
提醒採項目統計時區，指定星期及時間；有期限且未達標的目標另有到期日提醒。
最多安排 60 個本機通知，超出時明確拒絕設定。系統可能因 Focus 等設定延後顯示。

## Widget 第一版

`GoalTrackerWithWidget` scheme 只提供單一小型唯讀 Widget。透過原生「編輯小工具」選擇任一未封存項目，每個 Widget 各自保存 UUID，不限前三項；未設定時沿 App 排序採首項。已選項目刪除／封存後顯示不可用，不能悄悄替換成其他項目。數值顯示最新值；完成項目顯示當期次數與今天有無完成紀錄。點擊整個 Widget 開啟所選項目的新增紀錄 sheet；今天已有完成紀錄時開啟既有紀錄。
舊 `goaltracker://today` URL 仍回到首頁，失效或已封存項目回到首頁。

App Group `group.com.stu00608.mygoaltracker` 只供 App 與 extension 分享進度摘要，
只包含顯示需要的有限圖表點、位置與縮圖，不分享筆記或完整照片；
資料庫與完整附件仍保存在原本的 App 私有容器。
儲存、刪除、還原、封存、排序及語言變更後更新摘要；保存成功但摘要更新失敗時，
紀錄保留並顯示錯誤。Widget 依各項目的統計時區在日期／規則界線重算，
更新時機由系統管理，不保證每次修改後立即顯示。

Widget 跟隨系統亮暗外觀，文字跟隨 App 選擇的三種語言；原生 Widget gallery
使用系統語言。核心 `GoalTracker` scheme 不嵌入 Widget 或要求 App Groups，
兩個版本使用同一 App bundle ID 與私有資料位置，重新安裝時保留紀錄。

## 追蹤項目內容與目標進度

項目可選填文字說明（最多 10000 字）、HTTP／HTTPS 網站連結（最多 2048 字）與最多 10 張照片。網址明確點按才開啟，項目照片與紀錄照片各自保存。詳情可查看說明、開啟網站與放大照片，卡片背景可獨立選擇項目第一張照片。

數值詳情可切換折線圖與目標進度圓環。起始值為規則生效時最後已知值；沒有時取生效後且期限內首筆。現在值採不晚於現在與期限的最後已知值，比例為 (現在值−起始值)/(目標值−起始值)，支援向上／向下、零及負值；圖形限制在 0–1，文字保留真實數值。起始已符合門檻，或期限前有效紀錄曾達標，顯示滿環；目前值回落不撤銷有證據的曾達標狀態。沒有目標或基準時顯示無法計算的原因。修改／刪除資料使曾達標失去依據時重新計算。

## 位置判定與事件提醒

位置條件是達成條件的一種類型，納入下述條件組及條件邏輯。地點以搜尋與地圖選取，不提供目前／上車／下車或自訂半徑；半徑固定 200 公尺，是產品預設而非精度保證。照片 GPS 不作達成條件的判定依據，紀錄附帶位置仍由獨立開關決定。

以地理距離及水平誤差判斷：距離＋誤差不大於半徑才確定在內；距離−誤差大於半徑才確定在外；其他為不確定。儲存所需的新鮮位置最多等待 8 秒；權限拒絕、位置過期、精度不足或未符合時，於輸入頁說明，保留目前輸入與既有資料，不宣稱另有保存草稿。符合時直接儲存，沒有額外成功訊息。列表與網格快速完成皆使用相同驗證；刪除或取消完成不重新檢查。

時間／星期及期限提醒設於各項目。設定的 App 提醒總開關預設開啟，關閉時所有已安排的 App 提醒與條件監測停用，保留項目選擇；重新開啟後依目前權限重建，不僅停用畫面上的開關。條件符合提醒監測整組狀態，初始／設定變更先校準不發通知，確定未符合轉為符合時提醒並有 2 小時冷卻。系統區域監測最多 20 個不同中心點，重複中心共用，超過時明確拒絕設定，不任意淘汰。需要 Always 定位及通知授權，單純紀錄只需使用 App 期間定位；只有啟用相關功能才請求權限，不持續啟用 GPS。背景狀態不確定或過期時保守處理。封存、刪除或關閉項目提醒時移除其監測與通知；點提醒進入該項目新增紀錄。

區域事件及通知由 iOS 排程，不能保證立即、精確或每次送達，需真機驗證 Always 權限、背景喚醒、Focus 及重新啟動。主畫面 Widget 照片背景可在選定文字角落使用半透明漸層提高文字可辨識性，依原色／深色／調色／透明模式調整，不新增文字底板或內層卡片。

## 品牌

名稱為「Goalooker - 過路客」，主畫面短名稱依語言使用 Goalooker／過路客。保留既有 icon、bundle ID、URL scheme 與儲存位置。設計以浩瀚宇宙與短暫人生為意象：渺小的日常行動也能留下可見足跡，讓使用者看見自己的成長與影響。這個理念以簡短文字及克制的視覺呈現，日常紀錄仍是主要工作。

## 達成條件與條件組（v3）

設定名稱統一為「達成條件」，組合操作稱「條件邏輯」。有條件時至少一組，最多 10 組，每組 1–10 個條件；組名選填，以「條件組 1」等佔位。每組內部與最外層各自選「全部／任一」。僅一組／一個條件時相應邏輯控制停用，不改變運算。舊位置條件按原 ALL／ANY 移到組內；超過 10 個舊條件依序拆成每組最多 10 個，內外採原邏輯、ID 與順序保持穩定。不能以空組、未知類型或非法範圍覆蓋既有資料。

- 位置：指定地標 200m 範圍內／外，沿用精度與不確定性處理。
- 時間：HH:mm–HH:mm，包含選定的起訖分鐘，跨午夜可用；相同起訖代表全天。
- 星期：Calendar 星期日=1 至星期六=7，可複選。時間與星期皆依項目的既有統計時區及真正現在時間，補登不改用過去時間；跨午夜時以當下星期判斷。
- 步數／睡眠時數：嚴格大於／小於門檻，當日／當週／當月至現在的曆法區間。當週沿用週一開始的統計週；星期顯示順序是獨立偏好。步數以 HealthKit 原生 cumulativeSum 統計可讀取資料，睡眠只算 asleep 類型，跨來源與階段重疊取時間聯集，裁切至期間內，排除 inBed／awake。跨午夜睡眠分別計入兩個曆日，不宣稱是「昨晚」的完整睡眠。

健康整合唯讀，連線、資料用途及權限說明集中於設定頁的「Apple 健康」bottom sheet。新增條件選單在連線流程未完成時只提供位置、時間及星期，在條件區顯示一次「連接 Apple 健康，使用更多條件」提示，點擊開啟同一個設定 sheet，不切換分頁或丟失未儲存的編輯內容。對應資料類型的系統連線流程完成後，提供步數或睡眠條件；任一類型已完成設定便不再在編輯頁顯示連線、健康介紹或存取說明，新增其他類型的存取集中在全域設定。既有健康條件仍保留並可編輯，不能因權限狀態刪除、隱藏已設定的達成要求。全域設定請求本 App 支援的步數及睡眠讀取權限，不寫入健康資料。Apple 不揭露是否拒絕讀取，因此「系統不再需要授權提示」不能宣稱為「已授權」；無樣本或不可讀皆為未知，不能當作零通過小於條件。健康樣本與中間結果只在記憶體中，未寫入備份、Widget、分享圖或通知。

紀錄頁以可記錄為主：尚未能確認整體達成時，在輸入頁最上方以大紅色 X 及「條件未達成」提示；整體達成時不顯示提示。條件區僅顯示條件文本、選填的已讀數值及各條件右側的 ✓／X／?（綠／紅／橙），檢查中的條件亦顯示 ?；VoiceOver 使用明確狀態詞。條件組保留必要的名稱與邏輯但不顯示結果標誌，移除整體結果列、逐條狀態文字、讀取時間、原因及重複說明。必要的定位授權／重試動作仍可使用。未知仍不符合儲存要求，不能因簡化畫面放寬判定。

條件預覽的狀態生命週期由紀錄頁管理，不能依賴條件列是否在螢幕上；前景期間用 HealthKit observer 監聽樣本變更並合併重讀，回到 App 及每分鐘（含曆法期間切換）重算；離開頁面或背景時取消查詢與監聽，不啟用 HealthKit 背景傳送。即時指 Apple 可讀樣本的更新事件，不保證感測資料即時入庫。預覽位置只在已有權限時取得，未授權使用明確的「檢查位置」動作，不請求 Always 或暫時完整精度；儲存需要時可請求 When In Use 與完整精度。先判斷時間／星期，已能確定整體結果時避免不必要的資料要求。新增、補登及修改數值／增量／日期需在最後儲存前獨立重新驗證；只改照片／說明／紀錄位置、刪除與取消完成不受 gate 阻擋。失敗保留輸入頁內容與原資料，不宣稱存在可另行找回的「保存草稿」。

條件提醒限具有位置且不含健康條件的組合，由原生位置事件觸發後重算完整內外邏輯、時間及星期；沒有位置或含健康條件時開關停用並說明。時間條件只過濾位置事件，不保證已在地點內時會於時間窗開始通知；定時提醒仍用既有「時間與星期」。背景手機鎖定時健康資料可能不可讀，不安排聲稱會即時確認健康／位置全式的時間通知。位置監測全 App 最多 20 個不同中心，100 個僅儲存時檢查的位置條件不佔監測名額。未知不通知；初次／改設定安靜校準，保留冷卻與總開關。

設定新增「星期第一天」：週日初始／週一可選，同步條件星期列與日曆畫面；不修改既有統計週、紀錄 localDay 或目標歷史。

## 里程碑與完成卡片

項目可選持續追蹤／有限目標。舊完成型預設持續、數值型預設有限；完成與封存獨立。有限項目的當前目標達成後顯示完成狀態，仍能查看、編輯與記錄；設定新目標或改為持續可繼續。未設定目標的有限項目可手動完成，儲存前同樣檢查達成條件；重新開啟須確認並移除手動完成卡片，原紀錄保留。

數值完成沿用「期限前曾達門檻」的同一判定，未來事件不算；若證據早於目標生效，完成時間為生效時刻。進度環、期限提醒與里程碑使用同一 helper。每個數值目標一筆；持續頻率目標每週／月規則期間一筆完成歷史，有限頻率目標每個規則保留首次達成的期間，之後跨週／月仍維持完成，新的規則才重新開始。頻率以首次達到 N 個不同當地完成日期為準。自動完成由紀錄及歷史規則推導，不複製保存照片；補登、編輯、刪除會更新或移除失去依據的成就，不重複計數。持續項目詳情顯示完成歷史，底部「完成」分頁可查看全 App 成就。首次載入、還原與規則編輯不自動彈出慶祝。

完成卡片使用完整選定背景及淺浮雕圖層，支援轉動手機與手指拖曳；只在前景可見時開啟 CoreMotion，離開停止，減少動態效果採靜態。卡片下方「複製圖片／分享」輸出固定 2D 圖片，包含名稱、已知數值或完成狀態、達成時間、從規則／期間開始（不早於項目建立）到達成的時間，無數值時明確顯示未知，不捏造零。複製寫入圖片剪貼簿，分享開啟原生 share sheet，匯出失敗顯示錯誤。手動完成保留當時呈現快照，自動歷史呈現使用當前背景設定與可驗證的紀錄，避免多份附件佔用備份容量。

進度環背景使用滿版環形與中央百分比／目前值對目標值（例如 50/100），項目內可選樣式；不在角落重複數值，標題及選填日期仍遵從文字位置設定。小型 Widget 與 App 共用呈現設定。

## 操作狀態訊息

紀錄、首頁快速完成、項目編輯及地點搜尋等可重試的操作失敗，以共用原生浮動 toast 顯示，使用語意色文字、圖示及明確關閉操作，不插入紅字欄位或推動布局。保留輸入與原資料；一般暫態通知 8 秒後關閉，儲存／資料操作失敗則保留到使用者關閉，VoiceOver 或無障礙大字級時由使用者關閉，減少動態效果用淡入淡出，減少透明度用實色背景。條件符合／不符合／未知的持續狀態仍與條件相鄰；數值欄位的即時驗證及破壞性確認維持原生對應方式。
