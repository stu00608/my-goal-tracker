Integration APIs:

- `@MainActor RecordConditions.verify(tracker: Tracker) async throws`: silent success; throws `ConditionError` with a localized `key`, or CancellationError. Master adds `case let error as ConditionError: text(error.key)` to L.error and callers preserve full drafts on failure/cancel.
- Gate uses a separate fresh live CLLocationManager, kCLLocationAccuracyBest and startUpdatingLocation, stopping on first determinate result or 8-second fix timeout. Only reduced-accuracy gate Save asks temporary full accuracy with purpose key GoalookerCondition. Fresh fix <=60 s with 5 s future clock tolerance, valid coordinate and nonnegative finite accuracy; geodesic distance+accuracy <=200 means inside, distance-accuracy >200 means outside, overlap is unknown. No EXIF, record-location or photo writes.
- `Reminders.enabled`: L.defaults remindersEnabled Bool, absent => true. `Reminders.requests(_:now:enabled:)` creates pure calendar/deadline plans, <=60, no archived trackers. `Reminders.validate(_:now:)` also reserves one condition notification slot per eligible tracker and validates <=20 unique centers. `Reminders.sync(_:requestPermission: Bool = false) async throws`: startup never prompts; explicit global ON can request notifications. Global OFF clears owned pending/delivered IDs even without notification authorization.
- `ConditionReminders.shared.start()`: early launch/bootstrap. `sync(trackers:enabled:notificationsAuthorized:)` configures preference without requesting permission. `requestAuthorization()` is called only by explicit condition reminder Save, requesting When In Use before Always. Missing Always/Precise Location or denied notifications render inactive explanations.
- `GoalookerAppDelegate: UIResponder, UIApplicationDelegate, UNUserNotificationCenterDelegate`: master wires UIApplicationDelegateAdaptor. didFinishLaunching starts the singleton before scene setup; notification responses validate owned ID and userInfo["url"] then open goaltracker://record/UUID. Foreground owned notifications respect global OFF, foreign provider presentation remains permitted.
- Native CLMonitor name GoalookerConditions; centers round to 5 decimal places and share a stable hashed native ID across trackers and inside/outside relations. No continuous background GPS. iOS18+ retains CLServiceSession(.always) only with already-granted Always/full accuracy; early startup immediately retakes an outstanding session from existing history before Ledger/notification awaits, and OFF/permission loss releases it. iOS17 uses CLMonitor directly.
- Persisted per-tracker history contains only configuration signature, last known aggregate and lastNotifiedAt. Native CLMonitor records remain region-state source. States older than 12h are unknown; ALL conservative, ANY permits a known matching state. New/config-changed/global-reenabled configurations wait for all initial relevant states and prime silently. Warm background relaunch keeps prior aggregate so a fresh native false-to-true event can notify. Unknown preserves last known aggregate, so met -> unknown -> met does not manufacture a transition. Cooldown is 2h; fresh native trigger must be <=60s. Shared centers can notify each eligible tracker once. Disabled/deleted/archived trackers remove native conditions and owned condition pending/delivered notifications.
- Ownership matcher handles legacy UUID.weekday (1...7), UUID.deadline and goalooker.condition.UUID, leaving unknown providers untouched. Capacity includes planned time requests, pending condition requests and foreign pending requests.
